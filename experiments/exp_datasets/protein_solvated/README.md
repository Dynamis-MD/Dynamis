# Protein + Explicit Water (Solvated)

Proteins in PBC box with explicit water molecules.

## Files

| File | Atoms | Source | Equilibrated? | Description |
|------|------:|--------|:---:|-------------|
| dhfr_23k_openmm.xyz | 23,558 | OpenMM openmmtools | Yes | DHFR + TIP3P water, 62² Å box |
| 1aki_density.xyz | 25,846 | PDB 1AKI + grid water | No | Lysozyme, 7.6% protein |
| 2rik_density.xyz | 112,727 | PDB 2RIK + grid water | No | Titin I-band, 1.9% protein |
| 9gmo_density.xyz | 1,536,442 | PDB 9GMO + grid water | No | Large complex, 14.9% protein |

**Recommended for paper**: `dhfr_23k_openmm.xyz` and `apoa1_92k_openmm.xyz` (pre-equilibrated from OpenMM). The `*_density.xyz` files use grid-placed water (not MD equilibrated).

## Source and Method

**Equilibrated systems** (dhfr, apoa1):
- DHFR: `pip install openmmtools` → `openmmtools.testsystems.DHFRExplicit()`
- ApoA1: downloaded from `https://raw.githubusercontent.com/openmm/openmm/master/examples/apoa1.pdb`
- Both are pre-equilibrated by OpenMM developers

**Grid-water systems** (1aki, 2rik, 9gmo):
- Protein atoms extracted from existing PDB via covalent bond BFS
- Water placed on grid at liquid density (~0.100 atoms/ų), random orientation
- Generated by `test/generate_solvated.py`
